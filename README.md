# Curso de Kotlin desde 0

¡Comienza tu primer y emocionante viaje con la programación en Kotlin! Descubre cómo trabajar con variables, controlar el flujo de código y comprender los conceptos esenciales de la programación orientada a objetos.
Kotlin es el lenguaje preferido de Google para el desarrollo de aplicaciones de Android.
Domina el lenguaje con esta guía en español.
Aprende Kotlin para el desarrollo de aplicaciones de back-end, front-end y Android para ampliar tu alcance en múltiples plataformas con un lenguaje conciso.
