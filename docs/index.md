# Curso de Kotlin desde 0 en español

Si quieres aprender Kotlin, aquí tienes un curso en español.

Con lecciones para ir aprendiendo desde 0 hasta profundizar en sus diferentes usos.

## ¿Que es Kotlin?

Kotlin es un lenguaje de programación moderno a la vez que maduro, diseñado para hacer más felices a los desarrolladores.

Es conciso, seguro, interoperable con Java y otros lenguajes, y ofrece muchas maneras de reutilizar código entre múltiples plataformas para una programación productiva.

## Como aprender a programar en Kotlin

Aquí te ofrecemos unas guías de estudio, para hacer más ameno su aprendizaje.

Pero ten en mente siempre una cosa, la mejor manera de aprender un lenguaje, es practicando.

Así que tras cada lección habrá unos ejercicios para poner a prueba lo aprendido, y enlaces a [Retos de programación](https://retosdeprogramacion.com/).
